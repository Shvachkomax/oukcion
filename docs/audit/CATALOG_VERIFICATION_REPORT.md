## 4. Внесённые исправления

1. `lib/artists.ts` — общий хелпер `decodeSlug` (однократное декодирование,
   безопасная обработка некорректных percent-последовательностей).
2. `lib/artists.ts` — `getArtistBySlug`, `getProductBySlug`,
   `getPublishedProductsByArtistSlug` возвращают `LoadResult` и различают
   «не найдено» и «ошибка БД».
3. `lib/artists.ts` — исправлен подсчёт товаров персоны: запрос использовал
   недекодированный `slug` вместо `decodedSlug`.
4. `app/catalog/page.tsx` — сообщение о пустой выдаче показывается только при
   `status === "ok"`, при ошибке БД выводится отдельный текст.
5. `app/products/[slug]/page.tsx`, `app/artists/[slug]/page.tsx` — состояние
   ошибки БД вместо 404; добавлен показ «Остаток: N шт.».
6. `app/not-found.tsx` + `app/globals.css` — русская страница 404.
7. `docs/audit/mock-postgrest.mjs` — управление отказом БД (`/error`, `/clear`)
   и корректная проекция `select=*`.

## 5. Границы проверки

### 5.1 Проверено в браузере на тестовых данных

Все перечисленные выше сценарии выполнялись в реальном Chrome против
изолированного mock PostgREST, в dev-режиме и в prod-сборке. Проверены:
маршруты, фильтры, поиск, сортировки, кириллические URL, 404, отказ БД,
восстановление после отказа, мобильная вёрстка.

### 5.2 Проверено на настоящем PostgreSQL

Ничего. Локальный PostgreSQL запущен, но требует аутентификации и недоступен
без credentials. Конкурентные тесты атомарности rate-limit на настоящем
PostgreSQL **не выполнялись**.

### 5.3 Требует проверки с реальным Supabase

- RLS-политики `artists` / `physical_products` для anon-доступа: скрывают ли они
  черновики на уровне БД, а не только фильтром в коде.
- Реальные медиа-URL из бакета `oukcion-media`.
- Поведение на реальных данных и индексах.
- Запись в кабинете оператора (server actions, service_role, загрузка файлов).
- Rate-limit входа на настоящем PostgreSQL (конкурентные попытки, блокировка).

**Mock-фильтрация в коде не является проверкой RLS.** Mock отдаёт уже
отфильтрованные данные и никак не воспроизводит политики Postgres.
